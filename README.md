# 🧭 悬浮窗管理中心 (Floating Window Hub)

一款适配 **SillyTavern / 酒馆** 环境的悬浮窗收纳管理插件。把页面上散落的各种悬浮窗统一收纳进一个入口，通过一个悬浮球统一开关、呼出、代理操作，**界面清爽、不重叠、手机与 PC 通用**。

---

## ✨ 核心功能

### 1. 一键收纳悬浮窗
- **扫描页面**：自动识别页面上的悬浮窗（原生 DOM / jQuery / Vue / React、异步外链脚本的类型都能识别），点一下即收纳。
- **手动添加**：页面扫描不到时，用「＋ 添加配置」输入名称 + CSS 选择器手动登记。
- **收纳即隐藏**：把悬浮窗加入后，原悬浮窗立即在页面上隐藏，只保留在管理中心里。

### 2. 统合所有悬浮窗
- 页面右下角一个可**拖拽、贴边吸附**的悬浮球，徽标实时显示收纳的数量，悬浮球是唯一入口。
- 点击打开管理中心面板，所有悬浮窗集中列出，无需再翻找页面。

### 3. 三种操作状态（三键一体）
每个悬浮窗都有三个独立控制：

| 按钮 | 作用 |
| --- | --- |
| **↗ 进入** | 直接呼出该悬浮窗的**内容面板**（相当于点开原悬浮球后的样子），并自动收起本面板方便查看 |
| **打开 / 关闭** | 一键切换「打开」（可见可互动）/「关闭」（彻底从画面移除） |
| **🙈 隐藏** | 保持对方**脚本继续运行**，但外部看不到也点不到 |

> 状态徽标三色区分：🟢 打开 · 🟡 隐藏 · ⚪ 关闭

### 4. 代理操作（隐藏后仍可点按钮）
把悬浮窗设为隐藏后，管理中心会**自动扫描它里的所有按钮**，生成「⚡替代操作」胶囊：
- 点胶囊 = 直接**触发原悬浮窗里那个按钮**（如打卡、签到），而原悬浮窗始终保持隐藏
- 也可在「编辑」里手动配置精确按钮：`按钮名|css选择器`

### 5. 防重叠布局
- 呼出悬浮窗内容时，自动挪到面板侧旁并保持可见，不会互相遮挡。
- 面板**可移动**（拖标题栏）、**可调整大小**（拖右下角），位置与尺寸自动记忆。
- 悬浮球默认抬高，避免与面板互盖。

### 6. 智能守护 & 抗刷新
- **MutationObserver 自动守护**：Vue/React 重建、异步 import 延迟渲染时，自动补回隐藏状态，收纳不失效。
- **延迟二次扫描**：自动补捕「后加载才出现」的悬浮窗。
- **目标缓存**：界面高频刷新时复用元素引用，不重复 `querySelectorAll`，流畅不卡顿。
- **状态持久化**：全部收纳/开关/位置设置存于 localStorage，重启酒馆自动恢复。

### 7. 批量控制
- 「全部显示 / 全部隐藏」一键管理所有悬浮窗。

### 8. 排列模式切换
- 收纳列表支持 **列表 / 网格** 两种排列模式，一键切换。

---

## 🎨 界面特点
- 蓝→紫渐变主题，状态彩色徽标、卡片式列表、hover 上浮投影。
- 收纳后自动显示原悬浮窗的**头像图标**，一眼识别。
- 复用酒馆主题变量，自动适配深/浅色皮肤，**不使用黑色字体**。
- 动画只走 transform/opacity，PC 与手机都流畅。
- 移动端支持底部抽屉式展开。

## 📦 安装

在酒馆 **扩展 → 安装扩展**，粘贴仓库地址：

```
https://github.com/sbai5575/floating-window-hub
```

或直接用 manifest 直链：

```
https://raw.githubusercontent.com/sbai5575/floating-window-hub/main/manifest.json
```

安装后刷新页面，右下角出现 🧭 悬浮球即成功。

## 🚀 使用流程

1. 点 **🔍 扫描页面** → 自动列出检测到的悬浮窗 → 逐个「添加」收纳。
2. 收纳后原悬浮窗立即隐藏，集中显示在管理中心。
3. 想用时：
   - 点「**↗ 进入**」→ 弹出该悬浮窗的内容面板；
   - 点「**⚡替代操作**」→ 直接触发原悬浮窗里的按钮；
   - 点「**打开**」→ 恢复显示，由原悬浮窗接管。
4. 想删掉收纳：点「**🗑 移除**」→ 原悬浮窗自动恢复显示。

---

## 🧩 已适配的悬浮窗类型
- **原生 DOM / jQuery** 悬浮球 + 分离式内容面板
- **Vue / React 外链脚本**（外链 `import '…js'` 延迟渲染的悬浮球）
- 异步 `import` 延迟渲染的各类酒馆辅助脚本

> 遇到检测不到或「进入」不弹出的脚本，可反馈对应脚本文件，进一步针对性适配。
